# Twitter(X) Revert the UI

X（旧Twitter）のプロフィールにあるメディア欄といいね欄を変更前の使い慣れたUIへ戻し、ダークブルーのDIMモードを復元するChrome/Edge拡張機能です。

## 機能一覧

- メディア欄・いいね欄・ブックマーク欄を使い慣れた以前のUIに戻します。
- 以前存在したDIMモードを再実装しました。

## プライバシーと権限

`https://mia4696.org/chrome-policy` を参照してください。

## インストール方法

1. CodeからDownload Zipを押し拡張機能のソースをダウンロードし展開してください。
2. Google Chromeの `chrome://extensions/` を開きます。
3. 右上の「デベロッパー モード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」を押し、1で展開したフォルダを選択します。

Edgeでは `edge://extensions/` を開き、同じ手順で読み込めます。
