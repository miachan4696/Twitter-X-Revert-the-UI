# Twitter(X) Revert the UI

X（旧Twitter）のプロフィールにあるメディア欄といいね欄を変更前のX純正UIへ戻し、ダークブルーのDIMモードを復元するChrome/Edge拡張機能です。

## 仕組み

Xの現在のプロフィールJavaScriptには旧UIと新UIの両方が含まれています。次のFeature FlagをX本体の起動前に `false` へ固定し、公式の旧UI側を選択させます。

- `responsive_web_profile_redesign_enabled`：画像と動画が混在する旧メディア欄
- `responsive_web_history_screen_enabled`：プロフィールの旧「いいね」タブ

新しい `/i/history/likes` を直接開いた場合も、ログイン中ユーザーの `/ユーザー名/likes` へ戻します。

DOMを見た目だけ加工する方式ではないため、旧版の次の動作をそのまま復元します。

- `/ユーザー名/media` に画像と動画が混在するメディア一覧
- 3列の正方形サムネイルグリッド
- 旧版の無限スクロールと投稿遷移
- X本体と同じテーマ・レスポンシブ表示

JavaScriptファイルの置換やDOMの疑似加工は行いません。ホーム、通知、投稿画面などは現在のXのまま動作します。

## DIMモード

`/settings/display`（またはXの表示設定モーダル `/i/display`）にある既存の背景テーマ選択肢の横へ「DIM」を追加します。「DIM」を選ぶと、X標準Darkを土台に次の配色を全画面へ適用します。既存の背景テーマを選ぶとDIMが解除され、そのテーマへ切り替わります。

- メイン背景：`#15202B`
- カード・モーダル：`#192734`
- ホバー：`#22303C`
- 境界線：`#38444D`
- アクセント：`#1D9BF0`

## プライバシーと権限

- Chrome APIの権限は要求しません。
- Xとtwitter.com以外では動作しません。
- 外部通信、解析、広告は行いません。
- DIMの有効・無効と復元用の以前のXテーマ値だけを、XのLocal Storageへ保存します。
- ログイン中のユーザー名は「いいね」ページのローカル転送にだけ使用し、送信・保存しません。

詳しくは `https://mia4696.org/chrome-policy` を参照してください。

## インストール・更新（Chrome）

1. Chromeで `chrome://extensions/` を開きます。
2. 右上の「デベロッパー モード」をオンにします。
3. 初回は「パッケージ化されていない拡張機能を読み込む」を押し、この `x-old-media` フォルダを選択します。
4. すでに読み込み済みの場合は「X 旧メディア欄」カードの更新ボタンを押します。
5. Xのタブをすべて再読み込みします。

Edgeでは `edge://extensions/` を開き、同じ手順で読み込めます。

## 不具合報告

不具合や表示崩れを見つけた場合は、[GitHub Issues](https://github.com/miachan4696/Twitter-X-Revert-the-UI/issues)から報告してください。

報告時に次の情報があると、原因を特定しやすくなります。

- 使用しているブラウザとバージョン
- 本拡張機能のバージョン
- 問題が発生したXのページURL
- 再現手順
- 可能であればスクリーンショット

## アンインストール

拡張機能の管理画面で本拡張機能を削除すると、アンインストールできます。
